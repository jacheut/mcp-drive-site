mcp-drive connects a locally operated MCP client to Google Drive for file uploads, downloads, folder listings, and sharing links.

How your data is handled ↗

A personal utility maintained by jacheut. This website is an information page; it does not sign you in or access your Drive.

What the application does

A direct connection
for file transfers.

01Upload & update
Send a local file to an authorized Drive folder, or replace a specific file while preserving its file ID.
02Download & list
Save requested file content to a local destination and inspect folder metadata to find the correct file.
03Share deliberately
Retrieve existing sharing links. Creating an “anyone with the link” reader permission requires an explicit upload option.

Authorization is separate.

The installed application uses Google's OAuth consent flow. It requests the Google Drive scope to work with files and folders your account can access. Credentials are stored in the operator's configured local environment. You can revoke access in your Google Account permissions.

mcp-drive is an independent utility, not a Google product. Google Drive is a trademark of Google LLC.
