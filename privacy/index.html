Privacy policy

mcp-drive is a personal Google Drive file-transfer utility maintained by jacheut.

Effective date: October 6, 2026 · Application name: mcp-drive

1. What this policy covers

This policy covers the locally operated mcp-drive MCP application and this information website. The developer does not operate a central application service that collects Drive files from users. If you run the application on another machine or through a third-party MCP client, that operator or client's data practices also apply.

2. Data accessed and why

The application requests the https://www.googleapis.com/auth/drive OAuth scope. This gives it broad read/write access to files your Google account can access, subject to Google's permissions. The scope is not limited to files created by this application.

For requested operations, it processes file and folder IDs, names, sizes, MIME types, parent folder IDs, sharing links, owner email metadata, and file content. This supports uploads, replacement of a specified file, downloads, folder listings, and retrieving sharing links. It does not scan file content for advertising, profiling, or model training.

3. Credentials, storage, and logs

OAuth authorization takes place with Google. Access tokens, refresh tokens, and OAuth client configuration are kept in files in the operator's configured local environment. File uploads are read from local disk; requested downloads are written to local disk. Protect these files and the machine that stores them.

Application or host logs may contain file names, IDs, local paths, progress, errors, and related metadata. MCP tool responses can include sharing links, owner email metadata, and local paths. The application is intended not to return downloaded binary content in tool responses, but the selected MCP client controls how responses and logs are stored or forwarded.

4. Transfers and sharing

The application exchanges authorization data, file metadata, and requested file content with Google's services to perform your instructions. Tool output is also provided to the MCP client you choose. If that client uses an AI provider or other remote service, information from tool output may be processed under that service's terms and privacy policy.

The developer does not sell Google user data or use it for advertising. An explicit make_anyone_reader upload option can make an uploaded file readable by anyone with its link; use that option only when public sharing is intended. Without that option, the application does not deliberately add an anyone-reader permission. Google Drive retains existing file permissions and applies folder inheritance as appropriate; a file or folder may already be publicly shared.

mcp-drive's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google data is not used to develop, improve, or train generalized AI or machine-learning models by this application.

5. Retention and deletion

Local credentials, downloads, and any saved logs remain until removed by the operator or the relevant host's retention controls. Cloud files remain in your Google Drive under Google's retention and account settings. Revoking this application does not automatically delete existing Drive files, downloaded copies, or records retained by your MCP client.

You can revoke the OAuth grant at Google Account third-party permissions. Then stop the application and remove its configured token file and any local data or logs you no longer need. Manage or delete cloud files directly in Google Drive.

6. This website

These static pages do not request Google login, read Drive files, include analytics scripts, load third-party fonts, or set application cookies. GitHub Pages hosts the website and may process technical request information such as IP addresses under GitHub's privacy statement.

7. Contact and changes

For questions about this application or this policy, contact the maintainer through the jacheut GitHub profile or the website repository's issue tracker. Do not include tokens, client secrets, private file contents, or sensitive personal data in a public issue.

Changes to this policy will be published on this page with an updated effective date.
